# Preserved Workspaces

Both folders are byte-preserved copies of the top-level Java workspaces. Do not compile into or edit these copies.

`Harvey Java` contains the more developed sources and assets. `Harvey Java 2` contains earlier prototypes. In the developed snapshot, both main methods launch Sidescroller2; the larger Sidescroller file is an additional unfinished draft. The browser restoration uses Sidescroller2 as the Original reference and documents deliberate repairs in `browser/RESTORATION.md` at the repository root.
